# AI System Specification

## Role

AI is a synthesis layer over evidence, not the source of truth.

## Pipeline

```
Raw sources
  ↓
Normalization
  ↓
Product/entity matching
  ↓
Topic extraction
  ↓
Sentiment / claim extraction
  ↓
Evidence aggregation
  ↓
Score calculation
  ↓
AI synthesis
  ↓
User-facing decision
```

## AI output

Every product analysis should support:
- short conclusion
- strengths
- weaknesses
- audience
- risks
- confidence
- evidence IDs
- source count
- generation timestamp
- model/version

## Grounding

AI must only make factual claims that can be traced to available evidence or explicitly state uncertainty.

## No hallucination

Never invent:
- reviews
- quotes
- sources
- prices
- specifications
- usage statistics
- confidence

## Prompt rules

Prompts must:
- define role
- define evidence boundary
- demand concise output
- require uncertainty
- prohibit fabricated evidence
- return structured output

## Consensus Q&A

Question answering must retrieve relevant product evidence before generation.

Answer structure:
1. short answer
2. evidence
3. caveats
4. confidence
5. sources

## Model changes

Store model and prompt version with generated analyses. Recompute when evidence materially changes or schema changes.

## Safety

Do not expose internal prompts, credentials or private user data.
